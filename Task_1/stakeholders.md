
# Карта стейкхолдеров

| Область | Стейкхолдеры | Что необходимо выяснить |
| --- | --- | --- |
| Бизнес-ценность и приоритеты | Бизнес-заказчик / директор по цифровым продажам | Цели, приоритеты, критерии успеха, допустимый риск, инвестиционные ограничения |
| Реальный order flow | Руководитель команды заказов и оформления | Happy path, исключения, ручные операции, точки принятия решений                   |
| Legacy-ограничения | Технический лидер / ведущий разработчик монолитного ядра | Модули, транзакционные границы, Oracle, скрытые зависимости, релизные ограничения |
| Клиентские проблемы | Руководитель клиентской поддержки | Зависшие статусы, расхождения, обращения и ручные сценарии |
| Платежи | Команда платёжных интеграций | Цикл оплаты, ошибки, ретраи, идемпотентность, RPO |
| Логистика | Команда логистики и доставки | Резервирование доставки, split shipment, переносы, партнёрские подтверждения |
| Каналы | Владельцы каналов и интеграций | Различия моделей заказов, контрактов, статусов и SLA |
| Данные | DBA / владельцы Oracle | Объёмы, нагрузка, топ запросов, схемы, архивирование, backup/restore |
| Нагрузка и устойчивость | Инфраструктура / эксплуатация | Capacity, пики, инциденты, мониторинг, RTO/RPO |
| Аналитика | Команда аналитики и отчётности | Прямые зависимости от Oracle, расхождения данных |
| Внешние ограничения | Платёжные провайдеры, службы доставки, маркетплейсы | SLA, API, rate limits, таймауты, схема отказов и обратная совместимость |
